Three lenses

Static code, the optimizer's plan, and the live instance.

Most tools watch one angle. dbopt fuses three into a single verdict you can act on.

Static · mature

Shift-left analysis

A token-level T-SQL analyzer — 102 rules across hygiene, sargability, deprecated syntax, plan shape, locking, tempdb, transactions, security and index design. Runs in your browser or as a CLI. No connection required.

Plan · mature

Execution-plan breakdown

Fetches the estimated plan — compile-only, the query never runs — and breaks down operator cost, scans versus seeks, and spill risk.

Live · on-demand triage

Pulse and triage

Watch real-time vitals on demand, and run a poller that samples Query Store, deadlocks and index usage into a local time-series for a pain report you read when you want it.

Private by construction

Your data stays on the box — until you say otherwise.

Built for the shops that cannot ship a query off-site by accident: pharma, finance, healthcare.

  • Never reads your rows

    Every query dbopt runs hits sys.* catalog views, DMVs or Query Store — metadata, never table data.

  • Read-only and reversible

    Estimated plans are compile-only. DDL is preview-only — Safe-Apply never runs a change for you.

  • One binary, no services

    Linux, macOS, Windows. SQLite for storage, the web UI embedded inside. Nothing else to install.

  • Two things leave, both your choice

    A prompt you hand to a cloud AI model, and an anonymous version check to GitHub you can switch off. That is the complete list.

What that F1 does and doesn't prove. The corpus is hand-authored, so the harness is self-graded: it proves no regression on the cases we wrote, not a measured real-world false-positive rate. 73 of the 102 rules currently have a scenario; the newer rule packs are still being backfilled, and a held-out third-party corpus is on the roadmap. Reproduce it yourself with cargo run -p eval -- --html.

Install

One self-contained binary. Run it, open the port.

Windows.msi · x64 installer macOS.dmg · Apple Silicon Linux.tar.gz · glibc or static musl
Or one line
# Linux & macOS
curl -fsSL https://dbopt.org/install.sh | sh

# Windows (PowerShell)
irm https://dbopt.org/install.ps1 | iex

# then
dbopt-backend            # UI + API on 127.0.0.1:3690
dbopt lint ./db --format sarif   # offline, for CI

Builds are not code-signed yet. Windows: More info → Run anyway. macOS: right-click → Open. Details · All releases and checksums
